# 🏋️ CMA Fitness Management System

## Project Overview

The CMA Fitness Management System is a group project for the System Analysis and Design module (CMPG311). The system is designed to help CMA Fitness gym manage members, trainers, class bookings, payments, and equipment efficiently.

This database system replaces the current manual processes and spreadsheets, improving accuracy, organization, and overall service delivery within the gym.

## Features

**Member Management:** Register members, track membership status, and store member information.

**Class Booking System:** Allow members to book fitness classes and prevent double bookings.

**Trainer Management:** Manage trainer schedules, sessions, and availability.

**Payment Tracking:** Record membership payments and track outstanding balances.

**Attendance Tracking:** Monitor attendance for each class session.

**Equipment Management:** Track gym equipment, maintenance, and repairs.

**Reporting:** Generate basic operational and financial reports.
